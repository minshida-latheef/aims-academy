\# AIMS Academy Website



Official frontend repository for \*\*AIMS Academy\*\*.



\## Brand Identity

\- \*\*Heading Font:\*\* Montserrat

\- \*\*Body Font:\*\* Poppins

\- \*\*Primary Color:\*\* `#8C2C3F` (Deep Maroon)

\- \*\*Accent Color:\*\* `#FCB433` (Golden Yellow)

\- \*\*Background:\*\* `#FFFFFF` (White)



\## Pages Included

\- `index.html` - Home Page

\- `about.html` - About AIMS Academy

\- `course-grid.html` - Course Listings

\- `blog-details.html` - Articles \& News

\- `gallery.html` - Campus \& Event Gallery

\- `contact.html` - Admissions \& Contact Form

\- `error.html` - 404 Error Page

\- `maintenance.html` - Scheduled Maintenance Page
